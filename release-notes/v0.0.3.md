## Multron Download Manager v0.0.3

### Update progress you can follow

- **Settings → Updates & About:** when you press **Download and install**, a progress bar now shows how far the download is, the downloaded and total size, the download speed and the time left.
- **Update when the app starts:** the update screen also shows the downloaded size and the speed next to the percentage.
- The progress is sent four times a second instead of on every piece of data, so the window stays smooth while an update downloads.
- Downloads of yt-dlp and FFmpeg report their speed the same way.

### Browser extension: hide the download button

The **Download** button that the extension shows on videos and in the corner of a page now has a small **×**. Click it to hide the button on that page. It comes back on the next page or the next video, for example when you open another YouTube video.

### Linux: Flatpak browsers from Flathub

Browsers installed from Flathub are now found and listed as *(Flatpak)* in **Settings → Browser Integration** and in the setup assistant: Chrome, Chromium, Ungoogled Chromium, Edge, Brave, Opera, Vivaldi, Yandex, Firefox, LibreWolf, Waterfox, Floorp and Zen.

- The assistant opens them with `flatpak run` and copies the extension into the browser's own folder (`~/.var/app/<app id>/`), which the sandboxed browser can always read.
- Downloads work right away, because the extension talks to the app over `127.0.0.1`.
- To let the extension also start Multron Download Manager when it is closed, the browser needs permission to start programs outside its sandbox. The assistant shows the command to run once, for example `flatpak override --user --talk-name=org.freedesktop.Flatpak org.mozilla.firefox`. Multron Download Manager does not change this on its own, because it loosens the browser's sandbox.

The browser extension is part of this release: reload it from your browser's extensions page, or run the setup assistant again from **Browser extension** in the sidebar.

### Updating

v0.0.1 and v0.0.2 update themselves to this version the next time they start.

For the Linux FFmpeg changes see the [v0.0.2 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.2), and for everything that came with the first release see the [v0.0.1 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.1).
