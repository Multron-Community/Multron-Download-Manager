## Multron Download Manager v0.0.2

A small update for Linux, and the first version that installs itself through automatic updates.

### New: FFmpeg installs itself on Linux

FFmpeg is needed for most video downloads, because sites such as YouTube send video and audio separately, and for MP3 conversion. Until now Multron Download Manager installed it automatically only on Windows and macOS; on Linux you had to install it with the package manager, and the AppImage did not bring it at all.

- On Linux (x86_64 and arm64) FFmpeg is now downloaded automatically on the first video or music download, the same way as on Windows. It also works from the AppImage, so distributions without a `.deb` or `.rpm` package, such as Arch Linux and CachyOS, need nothing extra.
- You can also install or reinstall it from **Settings → Media**.
- An FFmpeg that is already installed on the system is still used and left to the package manager. The copy that Multron Download Manager installed is checked for updates once a week.
- If FFmpeg cannot be installed automatically, the hint in **Settings → Media** now also shows the Arch Linux command (`sudo pacman -S ffmpeg`).

### Updating

- **From v0.0.1:** v0.0.1 updates itself to this version the next time it starts. On Linux, the `.deb` and `.rpm` packages ask for your password once to install the update; the AppImage replaces itself.
