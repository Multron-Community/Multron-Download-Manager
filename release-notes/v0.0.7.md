## Multron Download Manager v0.0.7

A Scan for malware button, password-protected archives, faster torrents and an update that can no longer get stuck.

### Scan for malware with Multron Cloud (testing)

- **Scan for malware button.** Every finished download now has a **Scan for malware** button that checks it with Multron Cloud, separately from your antivirus. The Cloud Malware Scan License Agreement is asked only the first time you press it. The button is on by default and can be hidden in **Options › Security**.
- **100 MB for the button.** Files up to 100 MB are uploaded when you press the button; the limit can be lowered. Larger files are still checked by their hash.
- **Automatic scanning is on by default.** The Cloud Malware Scan License Agreement is asked once, when Multron Download Manager starts; declining it turns automatic scanning off, and it can be turned on again in **Options › Security**. You pick which file types it checks: programs and scripts for your system are selected by default (on Windows `.exe`, `.msi`, `.dll`, `.ps1`, `.bat` and more; on macOS `.dmg`, `.pkg`, `.command`, `.sh` and more; on Linux `.AppImage`, `.deb`, `.rpm`, `.sh` and more), and archives, disk images, documents or any other type can be added. **All files** scans every finished download. The automatic upload limit stays at 15 MB by default.
- **Scan window.** Every scan you start, whether of a single file, a torrent or a folder, opens a window that shows the progress, elapsed and remaining time, how many files were uploaded to the cloud and how many were already known by their fingerprint, and what is happening to the current file: computing its fingerprint, asking the cloud, uploading it (with the percentage and size) or waiting for the analysis. Counters show clean files, threats, suspicious files and files that could not be checked, and a live list shows every checked file with its size, result and how it was checked. Threats appear in the list as soon as they are found, each with **Show in folder**. You can stop the scan or keep it running in the background, and open the window again from the download's Multron Cloud badge.
- **Fingerprints first, then uploads.** Like Multron WinCleaner, a scan now computes the SHA-256 fingerprints of all files and sends them to Multron Cloud in batches before anything is uploaded. Every answer is used as soon as it arrives, so files the cloud already knows get their result right away and unknown files start uploading while the rest is still being checked, smallest first. A file the cloud has seen before but could not classify is uploaded again for a fresh analysis instead of keeping its old *unknown* result, unless this PC already had it analyzed in the last 24 hours.
- **A much more stable cloud scan.** The scan no longer loses its connection while the server analyzes a large file: it sends a ping every 20 seconds, reopens a dropped connection by itself (waiting 2, 4, 8, 15 and then 30 seconds, for up to 4 minutes) and tries each file up to 3 times. A file the server keeps analyzing for too long (1 minute when another scan is analyzing it, 3 minutes for your own upload) no longer holds up the whole scan; it is marked *not scanned, scan it again later*, and the scan window says when the connection is being reopened.
- **Faster uploads.** Several connections work at once (4 by default): one checks fingerprints while the others upload, each with as many files in analysis as the server allows. Unknown files are compressed with Brotli before they are sent, so scripts and programs often need a fraction of the upload; files that are already packed are sent as they are.
- **New cloud settings.** **Options › Security › Cloud connection** has the same options as Multron WinCleaner: **Compress uploads**, **Remember file fingerprints** (files that have not changed are not hashed again) and the number of **Connections** (1 to 8).
- **Stop scan works right away.** Stopping used to wait until the file being uploaded or analyzed was finished; now it stops at once, also in the middle of an upload.
- **Scan all.** The new **Scan all** button in the toolbar scans every finished download in one go, in the same window, and shows which download each threat is in. While it runs, the button shows the progress; each download's own Multron Cloud badge is updated at the end. The button is on by default and can be hidden in **Options › Security**, separately from the Scan for malware button.
- **Password-protected archives.** A locked ZIP or 7z archive is no longer uploaded, because the cloud cannot look inside it. The download shows **Multron Cloud: password needed** and the password is asked right away. The archive is unpacked into a private folder, the files inside are scanned one by one, and the folder is deleted afterwards. The password is not saved or sent anywhere. Locked RAR archives cannot be opened yet; extract them with WinRAR or 7-Zip and scan the files.

### Clearer downloads

- **No more separate antivirus scan.** Multron Download Manager no longer scans finished downloads with Microsoft Defender or AMSI; your antivirus keeps checking them as usual, and finished files still get the SmartScreen / Gatekeeper mark. When your antivirus blocks or removes a download, it is marked **Blocked by your antivirus** and a notice appears. The *Antivirus scan* option is gone from **Options › Security**.
- **Clearer results.** The misleading *Scanned* label is gone. Downloads that Multron Cloud has not checked say **Multron Cloud: not scanned**; click it to scan.
- **A clearer Scan for malware button.** It is now a coloured button next to the download.
- **Download and scan notices.** Multron Download Manager now shows its own notice cards in the corner of the screen, above other windows, also while it is in the background, minimized or hidden in the tray. A card tells you when a download starts, finishes or fails, shows the result when the Multron Cloud scan of a download finishes, and warns when your antivirus blocks a download. Finished downloads can be opened or shown in their folder right from the card; clicking a card brings the download up in the app. The cards do not depend on the system's notification settings, so they also appear where Windows notifications did not. They are drawn as one solid panel with rounded corners in the app's light or dark theme, so they stay readable on any background, also on PCs without graphics acceleration. Both kinds can be turned off in **Options › Startup & Shutdown**, and **Also show notices inside the window** shows them inside the window while it is in front. When Multron Download Manager is in the background, minimized or hidden in the tray, *Download complete* and *Download failed* are always shown. **Show notifications** is on by default and is turned on once with this update.
- **Programs really do not start by accident.** Double-clicking the open button of a downloaded program could still start it, and double-clicking the program itself only showed a short note. Now both ask *Start this program?* first, in a new dialog that shows the file, its size and the site it came from, what Multron Cloud found and whether SmartScreen will check it. A file that was not scanned yet can be scanned right from the dialog with **Scan first**, and a file with a threat needs **Start anyway**. The question can be turned off with **Ask before starting downloaded programs** in **Options › Security**; the option is on by default and is turned on once with this update.
- **SmartScreen badge.** A download whose files got the "downloaded from the internet" mark now shows a **SmartScreen** badge (**Gatekeeper** on macOS), so you can see that the system will check it when it is opened.

### Fixes and checks

- **Already downloading?** Adding a link that is already in the list, or a torrent that is already there, now asks first in a system warning: *This file is already downloading* (or *already downloaded*), with **Download again**, **Show existing** and **Cancel**. This works for new tasks and for downloads sent by the browser extension.
- **No false antivirus alarms.** A download that failed with *access denied* is no longer reported as a threat; the error says the file may be open in another program, protected, or blocked. Only real blocks by your antivirus count as threats.
- **Multron Cloud results.** Files the cloud engine did not flag but has not verified as clean are now shown as *Multron Cloud: no threat found* instead of an error.

### Faster torrents

- **Public trackers added automatically.** Torrents and magnet links that are not private also announce to a well-known list of public trackers, refreshed once a day. They find more peers and start faster, and magnet links get their metadata sooner. Private torrents are never changed. You can turn this off in **Options › Torrent › Trackers**.
- **More peers.** The default limit is now 500 peers per torrent instead of 200. If you never changed it, it is raised for you.
- **Quicker peer connections.** Peers that do not answer are given up on after 5 seconds instead of 10, so the engine moves on to working peers sooner.

### Updates no longer loop

- This covers every way an update is installed: the update at start-up, the automatic update downloaded in the background and installed when the app closes, and the one you start yourself. If an update was started twice and the app still runs the old version, for example because the installer was cancelled or could not replace the files, Multron Download Manager stops trying for 12 hours. Instead of blocking the app on every start, it shows where to download the update. **Download and install** in **Options › Updates & About** always tries again.
- Releases are now refused when the version numbers inside the app disagree. A build that reported an older version than its release would otherwise keep updating itself.
