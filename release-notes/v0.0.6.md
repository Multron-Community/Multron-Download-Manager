## Multron Download Manager v0.0.6

A portable Windows version and the Multron Cloud scan.

### Portable Windows version

Next to the installer there is now `Multron-Download-Manager-0.0.6-x64-portable.zip`. Extract it anywhere, for example on a USB stick, and run `multron-download-manager.exe`. Nothing is installed:

- Settings, the download list, torrents and updates are kept in the `data` folder next to the program, not in your user folder.
- The portable copy updates itself in place with the signed portable package, and your `data` folder is kept. Every update is checked with the same signature as the installer.
- Delete `portable.txt` to make the copy use the normal per-user folders instead.
- A browser extension that is already installed, for example from the installed version, connects to the portable copy too: Multron Download Manager asks you once to **Allow** it.

### Multron Cloud scan (testing)

Finished downloads can now also be scanned with Multron Cloud, the cloud scan from Multron Win Cleaner (viruskov.com OPEN-EDR engine). It runs separately from your antivirus on Windows, macOS and Linux, and its result is shown on the download as its own **Multron Cloud** badge next to the antivirus result.

- **Off by default.** Turn it on under **Options › Security › Multron Cloud scan** after you accept the Cloud Malware Scan License Agreement.
- **Hash first.** The SHA-256 of each file is checked first. Only a file the cloud has not seen yet is uploaded for analysis.
- **Upload limit.** Files up to 15 MB are uploaded by default; you can raise the limit to 100 MB. Larger files are only checked by their hash and are never uploaded.
- **Private folders stay private.** Your user name is replaced with `%USERPROFILE%` in the folder that is sent with a file, and the full path is not sent.
- The cloud scan is a test version and may report false positives, so check a detection before you delete a file.

### Safer opening and clearer scan results

- **Programs no longer start with a double-click.** Double-clicking a downloaded program (.exe, .msi, scripts, installers) used to run it right away, which was easy to do by accident. Now it does nothing unless you turn on **Options › Security › Start programs with a double-click**. The open button still opens it, and other files open as usual.
- **See why a file was not scanned.** Click the antivirus or Multron Cloud badge on a download to see the reason, for example that no antivirus is turned on or that the file is over the upload limit. The details panel at the bottom shows both results as well.
