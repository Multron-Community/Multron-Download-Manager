## Multron Download Manager v1.0.2

Dragging finished downloads out of the list now works.

### Fixes

- **Dragging downloads out works.** In 1.0.1, dragging a finished download to a folder, the desktop or another app started a drag but nothing was copied when you let go, because the dragged item did not carry the file. Now the file is copied like when you drag it from File Explorer, also when several ticked downloads are in different folders. Available on Windows.
