## Multron Download Manager v0.0.4

### The browser extension updates itself

Browsers do not reload an extension that was loaded with *Load unpacked* or *Load Temporary Add-on* when its files change, so until now the extension kept running its old version after Multron Download Manager updated.

- The extension now checks the version of Multron Download Manager every time it connects. When the app is newer, the extension reloads itself from the updated folder, once per version. Pages that were already open get the new buttons after a refresh.
- On Linux, the copies of the extension used by the AppImage and by Flatpak browsers are refreshed every time Multron Download Manager starts, so they update too.

**One last manual step:** the extension you have now does not contain this yet. Reload it once from your browser's extensions page (the circular arrow on the Multron Download Manager extension in Chromium browsers, **Reload** in Firefox's *about:debugging*), or run the setup assistant again from **Browser extension** in the sidebar. After that, it keeps itself up to date.

### Updating

Earlier versions update themselves to this version the next time they start.

For the update progress bar, the button to hide the extension's download button and Flatpak browser support see the [v0.0.3 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.3); for the Linux FFmpeg changes the [v0.0.2 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.2); and for everything that came with the first release the [v0.0.1 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.1).
