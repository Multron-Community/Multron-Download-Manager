## Multron Download Manager v0.0.8

A fix for automatic updates on macOS, Instagram stories and clearer sign-in messages, and VirusTotal links for every download.

### Fixes

- **macOS updates no longer get stuck.** After an automatic update, macOS could keep the "downloaded from the internet" flag on the new version, so Gatekeeper treated it as a new download and the update could be offered again and again. Multron Download Manager now clears that flag from the verified update and from the installed app, after the update's signature and SHA-256 have been checked. Thanks to İbrahim Emir Akman.
- **Instagram stories.** The browser extension now shows its download button on Instagram stories and highlights, and sends your Instagram sign-in along, so stories download while you are signed in to Instagram in your browser.
- **Clearer Instagram and sign-in messages.** A link to a whole Instagram profile used to fail with a confusing error that looked like a sign-in problem. Multron Download Manager now explains that a profile cannot be downloaded at once and that you can open the post or reel, or use **Download all from this page**. When a site only shows a video to signed-in users, the message now says how to download it: sign in to the site in your browser and use the extension, or choose your browser in **Settings › Media › Use cookies from browser**.

### Releases

- **VirusTotal links.** Every release now lists each file with a link to its VirusTotal report, found by the file's SHA-256, so you can look a download up before you install it.
- **Download buttons in the README.** The project page has buttons for Windows, macOS and Linux that lead to the latest release, and a counter of all downloads.

### Updating

Earlier versions update themselves to this version the next time they start.

For the faster, more stable Multron Cloud scan, the new start dialog and the other changes of the previous version see the [v0.0.7 release](https://github.com/Multron-Community/Multron-Download-Manager/releases/tag/v0.0.7).
