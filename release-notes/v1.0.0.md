## Multron Download Manager v1.0.0

Torrent search, a JDownloader-style link grabber, batch links, category folders in your language and custom categories, 24 languages in the app and the browser extension, security levels from Basic to Strict, adjustable brightness, a glass look and a simpler Multron Cloud scan window.

### Torrents

- **Torrent search.** The new *Torrent search* page in the sidebar searches several sites at once. Torrents-CSV and the Internet Archive are built in. Results from every site you turn on appear in one list with their size, seeders, leechers and date. You can sort them by seeders, size, date or name, show one site only and filter by name. *Download* opens the usual new download window, so you can still choose the folder and the files.
- **Ready-made IP blocklists.** *Torrent → IP Filters* offers BT BlockLists, iBlocklist Level 1 and 2 and Spamhaus DROP with one click. The manual ranges box is now clearly empty by default, and lists whose names contain a comma or that put a comment after each range (such as Spamhaus) are read correctly.
- **Add your own sites.** *Add a site* takes a search address with `{query}` where the search words go, for example a Jackett or Prowlarr Torznab feed or any site that offers RSS or Atom search results. Seeders, leechers and sizes are read from Torznab and Nyaa-style feeds. Each site can be turned on or off, and sites you added can be removed.

### RSS feeds

- **Find feeds.** The RSS page has a *Find feeds* area: search podcasts by name (also ones you know from Spotify or Apple Podcasts), or paste a website address to find its feeds. Built-in feeds from official sources that share their files legally are one click away: Ubuntu, Linux Mint, Fedora, Arch Linux, DistroWatch, FOSS Torrents, Academic Torrents and freely licensed films and music on the Internet Archive. Feeds that only give an info hash get a magnet link.
- **YouTube and YouTube Music.** Paste the link of a channel, an artist or a playlist to follow its new videos and songs. Spotify offers no feeds and its music is copy-protected, so it is not supported.
- **Internet Archive.** Follow anything on archive.org: a search (for example a topic or `collection:…`) with a media type, or everything new. Each item downloads completely through its own archive.org torrent.

### Adding downloads

- **More for torrents.** A separate folder for torrents, *Add torrents paused*, extra files such as samples, .nfo and .txt left unticked (with your own list), *One at a time* in Queueing so torrents download one after another, and the watch folder can delete .torrent files after adding them. Torrents also work with *Download later* and the scheduler.
- **Less babysitting.** Windows does not go to sleep while a download runs, downloads pause before the drive runs out of space (1 GB by default), failed downloads can be retried by themselves after a wait, the folder can open when a download finishes, and finished downloads can leave the list after a number of days.
- **LinkGrabber.** A new *LinkGrabber* page in the sidebar collects links before they are downloaded: links you paste, links copied with the link grabber turned on, *Add several links at once…* and everything that link-protection sites send with Click'n'Load. Each link is checked, so you see its size, its hoster and whether it is online, offline or unknown. Archive parts are grouped into packages with their total size and how many of their links are online. *Filters & options* at the bottom folds open to hide offline links, file types, extensions or hosters, an overview shows the totals, and *Start all downloads* (or *Start selected*) sends them to the download list in the folder you choose. Offline links can be removed with one click.
- **Find every file on a page.** Paste a web page address into LinkGrabber and the page is scanned: every file it links to or shows (archives, videos, music, images, documents, programs, also links hidden in scripts) is listed as a package named after the page, with where each link was found. *Also scan linked pages on the same site* goes one level deeper, up to 25 pages.
- **Analyse and add links.** *Add new links* in LinkGrabber opens a window with the save folder, a package name, a comment, the password for the archives with *Auto extract*, a user name and password for protected links, and a priority (start first or last).
- **Progress while scanning.** LinkGrabber shows a progress bar while it scans pages and checks links, with a *Cancel* button. *Filters & options → Speed* sets which file types are checked automatically (by default everything except images, scripts and web pages), how many links are checked at the same time (8), how long to wait for a page (25 seconds) and how many linked pages to scan (25).
- **Site rules.** *Settings → Site rules* teaches LinkGrabber how to find the files on a website: a site and a link pattern, with options to follow the found links one step and to turn a page link you add into its real download link. Each rule can be tested on a page, and rules can be shared by copying and pasting them. Rules only read pages; they cannot run code.
- **Link grabber.** Turn on *Settings → Files → Link grabber: watch the clipboard for links* and the links you copy (http, https and magnet, also several at once) are collected. A bar at the bottom of the window shows how many there are and opens them in the *Download from this page* window, where you pick the ones you want. Links already in the list are skipped. It is off by default.
- **Several links at once.** *Add several links at once…* in the new download window takes one link per line and opens them all for review. A number range like `file[01-20].zip` adds every number, with the zeros kept.
- **Hosts that ask you to wait.** When a site answers "too many requests" or "busy" (HTTP 429 or 503), the download waits as long as the site asks, up to 15 minutes, shows *Waiting (the site asks to wait)* with a countdown and then continues by itself instead of failing.
- **Expired links are renewed.** When a link stops working with HTTP 403 or 410, which is how many file hosts and video sites end a link after some time, the download shows *Refreshing the link*, asks the site for a fresh link and continues from where it stopped.
- **Download later and the scheduler.** *Download later* in the new download window puts a download into the queue without starting it. *Settings → Scheduler* starts that queue at a set time on the days you choose and can stop it again, for example to download at night. It can also start every paused download instead.
- **Stop all.** Next to *Pause all*, *Stop all* also stops seeding torrents.
- **Site logins.** Save a login (user name and password, or a token) for a site once in *Settings → Site logins*, and every download from that site, including several links at once and LinkGrabber, logs in by itself. The new download window has *Use authorization* with *Remember for this site*, and a download that fails with "login needed" (HTTP 401) offers *Log in…* and retries. Logins are only sent over HTTPS, and passwords are encrypted with your Windows account.
- **Sounds.** A short chime when a download finishes (on by default) and an optional lower tone when one fails.
- **Ask before every download, in its own window.** With *Settings → Browser Integration → Ask before every download* (on by default), every download from the browser opens a small window of its own instead of the main window. You change the folder, file name or quality there, and the download then runs in that window with a progress bar, speed, time left and connections, and you can pause, cancel or open it when it is done. It also appears in the main list.
- **Link-protection sites (Click'n'Load).** Sites such as filecrypt, keeplinks and linkcrypt have a *Click'n'Load* button that hands their links to a download manager. Multron Download Manager now answers it: the links open in the *Download from this page* window for review, and the archive passwords the site sends are saved for extraction. Pasting such a link in the app reads the page; if it shows a CAPTCHA, the page opens in your browser so you can solve it there. On by default in *Settings → Browser Integration*.
- **CAPTCHAs: you solve them, the rest is automatic.** When a site answers with a CAPTCHA (reCAPTCHA, hCaptcha, Cloudflare Turnstile and others) instead of the file, Multron Download Manager opens the page in your browser, plays a short chime, shows a notice and lists it under *N CAPTCHAs waiting* in the status bar. While it waits, the download is retried by itself, so it continues as soon as the site lets it through. Everything can be set in the new *Settings → CAPTCHAs* page: opening the browser, the sound, the notice, the retry interval and how long a CAPTCHA waits. Multron Download Manager never solves CAPTCHAs by itself and never sends them to solving services.

### Archives

- **Automatic extraction.** Finished ZIP, 7z and RAR downloads are unpacked into a folder named after the archive. Split archives (*name.part1.rar*, *name.7z.001*) wait until all of their parts have finished. ZIP and 7z are unpacked by the app itself; RAR and split archives use 7-Zip (or 7z / unrar on Linux and macOS) when it is installed.
- **Passwords for archives.** *Settings → Files → Passwords for archives* holds a list that is tried on locked archives. A missing password is shown on the download, with *Try again* once you have added it.
- **Safe by design.** Files are never written outside the target folder, and an archive that unpacks to far more than its own size is stopped, also for RAR and split archives unpacked with 7-Zip. Deleting the archive after extraction is optional and off by default.
- **Archive passwords as a list.** *Settings → Files → Passwords for archives* is now a list where passwords can be shown, reordered and removed. With one saved password, locked archives use it by themselves; with several, the download shows *Choose a password*, where you pick one, try them all or type a new one.

### Organize and find

- **Automatic backup.** Off by default. *Settings → Backup & restore → Automatic backup* saves a backup every week, month, 3 months, 6 months or a number of days, weeks, months or years you choose, keeps the last few and deletes older ones. Automatic backups never contain passwords or keys.
- **Statistics.** A page with how much you downloaded today, this week, this month and in total, a chart per day, the most used sites and the space each category takes.
- **Download history.** Everything you download is remembered, also after you remove it from the list. Search it, download something again with one click, and get a warning when you add a link you downloaded before.
- **Tags and notes.** Give downloads colored tags and a note in the new *Tags & notes* tab; tags appear on the download and as filters in the sidebar.
- **Command palette and shortcuts.** Ctrl+K opens a search for every action, setting and download. Ctrl+N, Ctrl+F, Ctrl+L, Ctrl+H, Ctrl+, , Ctrl+Shift+P/R, Space and Delete work as shortcuts.
- **Per-site limits.** A speed limit or a maximum number of connections for a single site.
- **Mirror links.** Backup links for a download; when one fails, the download continues from the next.
- **Rename and move rules.** Rules that rename finished files or move them to a folder by file type, site or name pattern, with {name}, {ext}, {date}, {host} and {category}.
- **Backup and restore.** One file with your settings, categories, rules, site logins, the download list and the history; passwords are only included when you choose to.
- Statistics, history, tags and the shortcuts can each be shown or hidden.

### Folders

- **Category folders in your language.** With *Sort into category folders* turned on, the folders (Video, Music, Documents, …) are now named in the app language, for example *Видео* and *Музыка* in Russian. Existing installs keep their English folder names until you choose otherwise.
- **Renamed when the language changes.** When you change the app language, Multron Download Manager asks whether to rename the category folders to match. Downloads in them move along, and a folder is skipped while one of its downloads is running.
- **Your own folders and categories.** *Settings → Files* lets you choose a different folder for each category. The **+** next to *Categories* in the sidebar opens a window for your own categories: a name, an icon from 24, the file types (with templates such as E-books, Subtitles, Fonts, 3D models or Disk images), its folder and a preview. Custom categories are edited with the pencil next to them.
- **Drag to reorder.** All categories in the sidebar, the built-in ones too, can be dragged up and down into the order you like.
- **Delete files by default.** A new setting ticks *Also delete the downloaded files* in the remove window by default. You can still untick it each time.

### Browser extension

- **24 languages.** The extension's menus, buttons, popup and notifications are translated into every language of the app.
- **Same language as the app.** The extension now uses the language chosen in the app instead of the browser's language, and switches within a few seconds when you change it.
- **A fresh look that follows the app.** The popup and the download button and menus on pages have the app's new look: slate-blue cards with depth, accent glow, switches and smooth animations. They turn light or dark together with the app's theme.
- **Progress window for browser downloads.** On by default: *Settings → Browser Integration → Show a progress window for each browser download* starts browser downloads right away and opens a small IDM-style window with their progress, speed, a speed limiter and what to do when they finish.
- **Only the options that fit.** The extension menu now lists only the qualities the video really has, up to its highest one, and *Best quality* shows which one that is. On sites that only have sound, such as SoundCloud or Bandcamp, it shows only the audio formats. Both are on by default and can be turned off in *Settings → Media* and *Settings → Browser Integration*.
- **Signed for Firefox.** The release now includes a Firefox add-on signed by Mozilla (`multron-browser-extension-firefox-v1.0.0.xpi`). Open it in Firefox and click *Add*; unlike a temporary add-on, it stays after Firefox restarts and also works in standard Firefox.
- **File types it leaves alone.** *Never take over these file types* in the popup takes a list of extensions, for example `pdf torrent`. Downloads of those types stay in the browser.

### Look

- **Glass effect.** Cards, buttons and fields get a soft sheen and a light top edge, like Multron Win Cleaner. It is on by default and can be turned off in *Settings → Appearance*.
- **Background image.** *Settings → Appearance → Background image* puts a picture of your choice behind the window, or one of five built-in backgrounds, photos by Karem Adem on Unsplash. The panels become see-through, and the panel opacity and a blur can be adjusted.
- **Your own color.** Next to the ready-made colors, *Custom color* lets you pick any color for buttons, progress bars and the window tint. Very dark or very light colors (even black or white) are adjusted just enough to stay readable, and the text on colored buttons switches between white and dark by itself. *Settings → Appearance → Readable colors* keeps the exact color if you prefer, *Button color* gives all buttons their own color apart from the accent, and *Text on buttons* picks the button text color.
- **A calmer layout.** The settings pages have a simpler title with the page's icon instead of a colored bar, and the header no longer cuts off the page title on smaller windows. Search, RSS and *Create torrent* sit at the bottom of the sidebar as rows or, if you prefer, as tiles (*Settings → Appearance → Sidebar*).
- **Arrange the sidebar.** Sources, Categories, Tags and Tools are groups you can drag up or down by the handle next to their title and fold away with a click. Every item, from Direct links and Video to LinkGrabber and RSS, can be dragged into any group, *New group* makes your own, and the round arrow resets the layout.
- **Reset categories.** *Settings → Files → Reset categories* removes your own categories and puts the folders, order and sidebar place of the categories back to the defaults. Downloaded files stay where they are.
- **24 languages.** Polish, Dutch, Ukrainian, Czech, Swedish, Romanian, Hungarian, Greek, Indonesian, Vietnamese, Thai and Hindi join English, Turkish, German, French, Spanish, Italian, Brazilian Portuguese, Russian, Japanese, Simplified and Traditional Chinese and Korean.
- **Language has its own page.** The app language moved from *Startup & Shutdown* to its own *Settings → Language* page.
- **Language files you can edit.** Every language is now a plain `.ini` file in the `lang` folder where Multron Download Manager is installed. To add a language, copy `en.ini`, name it after the language code (for example `pl.ini`) and translate it; *Settings → Language → Reload* picks it up without restarting. *Open language folder* goes straight there.
- **Easier on the eyes.** The dark theme uses a soft off-white instead of pure white for text and brighter grey for secondary text, and the light theme a softer, less glaring background with cards that stand out gently. Choice buttons, such as the languages, have clearly readable labels and visible radio circles, and the selected one gets a calm tint instead of a glow.
- **Brightness.** *Settings → Appearance → Brightness* makes the backgrounds of the light and the dark theme darker or lighter, each on its own slider, while text keeps its contrast. 0 is the default.
- **Clearer at a glance.** File-type badges in the list are colored by kind (video, music, documents, archives, programs, images), the details pane shows its information as a tidy table with pill-shaped tabs, LinkGrabber totals are shown as colored pills, and torrent search sites and built-in feeds get their own colored badges.

### Multron Cloud

- **A simpler scan window.** The scan window now shows one progress ring with the result in large letters, the current step in one line and small counters for clean files and threats. Threats are listed right away with *Show in folder*; the list of all files opens with *All files*.
- **Cloud-based malware protection, easy to find.** The new *Settings → Multron Cloud* page starts with a *Cloud-based malware protection* box that explains what Multron Cloud does: it checks your downloads for viruses and other malware in the cloud, separately from your antivirus. Real-time scanning (*Scan finished downloads with Multron Cloud*) and the agreement are right there.
- **Security alert in the corner.** When a scan finds a threat, a red alert with a warning sound appears in the bottom-right corner, like an antivirus, and stays until you close it. *Show the threat* opens the scan report. The separate download window shows the same warning.
- **Quarantine.** Files that Multron Cloud finds malicious are moved to a locked quarantine folder and renamed, so they cannot be started by accident. *Settings → Multron Cloud* lists them with *Restore* and *Delete*.
- **Scan history.** Every finished scan is kept with its date, result and details, and can be filtered by threats, clean files and unfinished scans. Entries older than a month are deleted by themselves (1 week, 3 months, 1 year or never can be chosen).
- **Threats do not open by accident.** Files marked as a threat or suspicious only open after you confirm it in a warning.
- **Checked again before opening.** A download that was never scanned, or whose last scan is older than 7 days, is checked by Multron Cloud when you open it, and opens when it is clean.
- **VirusTotal.** Finished downloads get a *VirusTotal* button. Without a key it opens the file's report on virustotal.com by its SHA-256 fingerprint, so the file itself is never sent. With your own free API key (*Settings → VirusTotal*, stored encrypted with your Windows account) the result appears in the app, with how many of more than 70 engines flag it. A file VirusTotal does not know yet is only uploaded after you agree.
- Each of these can be turned off separately.
- **Protected.** While automatic scanning is on, the status bar shows a green shield with *Protected*. Clicking it opens the security settings.

### Safer downloads

New options in *Settings → Security → Safer downloads*:

- **Program files in torrents are left unticked.** When a torrent contains programs or scripts (.exe, .bat, .scr, …), they are not selected and a warning is shown, because fake videos and games often hide malware this way. On by default.
- **Disguised programs are marked.** Files whose name hides that they are programs, such as *invoice.pdf.exe* or names with hidden right-to-left characters, are marked in the list and always ask before they start. On by default.
- **Only encrypted links.** An optional setting refuses links that start with `http://`, because anyone on the network can read or swap what they download. Torrents are not affected.
- **Real file type check.** A download that is really a program although its name says otherwise, such as an .exe renamed to .pdf or .mp3, is marked as a disguised program, raises an alert and does not open without a warning.
- **Digital signatures.** On Windows, downloaded programs are checked with Authenticode: signed ones show their publisher, unsigned or broken ones are flagged in the list and before they start.
- **Programs from the browser are always shown first.** Programs and scripts that the browser extension sends open the small download window before they are saved.
- **Click'n'Load hardened.** It only answers requests for the local address, accepts at most one batch every 1.5 seconds and can be limited to known link-protection sites.
- **Security level.** *Settings → Security* starts with a *Security level* slider, like the User Account Control settings in Windows: Basic, Standard (the default), High and Strict, from *Fewer questions* to *More protection*, with what each level does next to it. It sets all the security options at once, and shows *Custom* as soon as you change one of them yourself.
- **Programs only over encrypted links.** Optional (on from *High*): programs and scripts from links that start with `http://` are refused, because they could be swapped on the way. Other files still download.
- **No local network links from the browser.** Optional (on from *High*): links to your own network, such as 192.168.x.x, localhost or a router, are refused when the browser extension or Click'n'Load sends them, so a web page cannot make Multron Download Manager reach devices at home.
- **Ask before opening any file.** Optional (on in *Strict*): every downloaded file, not only programs, asks once before it opens.

### Privacy

- **Download through Tor.** The new *Settings → Privacy* page sends link and video downloads through Tor, including name lookups, so the site sees a Tor address instead of yours. Multron Download Manager finds a running Tor Browser or Tor service and can test the connection. If Tor stops, downloads stop instead of going out directly. A *Tor* badge in the status bar shows that it is on.
- **Torrents stay off Tor.** BitTorrent would reveal your real address even through Tor, so torrents are blocked while Tor is on (this can be turned off).
- **More privacy options.** Ask sites not to track you (Global Privacy Control and Do Not Track), hide file names in notifications, and clear the download history on exit.
- **Leave fewer traces.** Optional: do not send the page address (Referer), remove finished downloads from the list on exit, delete saved site cookies on exit and do not remember LinkGrabber links.

### Speed

- **Faster start.** The first connection of a download now reuses the connection that checked the file size, so every download starts without one extra connection setup.
- **YouTube with all connections again.** YouTube now makes a video's files available a few seconds after they are found. Multron Download Manager waits for that moment instead of asking too early, so YouTube videos download with the multi-connection engine again instead of falling back to a single yt-dlp connection.

### Video quality

- **Only the qualities the video has.** The quality list in the new download window now goes up to the highest quality of the video, and *Best* shows which one that is, for example *Best (1080p)*. A default quality the video does not have becomes *Best*. It is on by default and can be turned off in *Settings → Media*.
- **No more sound-only videos.** Instagram stories and some high-quality YouTube videos come as VP9 or AV1 inside an .mp4 file, which the Windows player cannot show, so only the sound played. With *MP4 H.264* (the default format), such videos are now converted to H.264 after downloading, so every player shows the picture. A video that arrives with no picture at all is downloaded again in a format that has one.
- **Steady size while downloading.** For sites that only give approximate sizes, such as Facebook, the total is now worked out for the picture and the sound together from the start, so it no longer jumps up halfway through.
- **Facebook videos in WebM.** Facebook offers its videos only with AAC sound, which a WebM file cannot hold, so saving them as WebM failed with *Conversion failed*. Such videos are now saved as MP4 (or MKV) instead.

### Linux

- **Runs on Ubuntu 22.04.** The `.deb` and the AppImage are now built on Ubuntu 22.04, so they also run on Ubuntu 22.04, Linux Mint 21, Pop!_OS 22.04 and other distributions with glibc 2.35 or newer.
- **Flatpak and Snap.** Multron Download Manager can now be built as a Flatpak and a Snap. In those versions, updates come from Flathub and the Snap Store instead of the app, and the browser extension and its native messaging host are set up for the sandbox.

### Updating

Earlier versions update themselves to this version the next time they start. The browser extension reloads itself within a minute of the app update; refresh tabs that were already open.
